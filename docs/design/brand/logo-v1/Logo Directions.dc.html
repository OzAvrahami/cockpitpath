A bent route leg with two waypoints — a filled fix at the turn, an open fix at the destination. Reads as a flight path and a learning path at once: each turn is a step understood before the next.

RECOMMENDED DIRECTION · REFINED
Route & Fix
One bent route leg, a filled fix at the turn, an open fix at the end. It is the only one of the three that literalizes the product name without drawing an aircraft, and the only one still identifiable as two strokes and a dot at 16px. The vertex fix reuses the same cyan already reserved in-product for the current step and the current action, so the mark and the interface read as one system rather than a logo bolted onto an unrelated UI.
