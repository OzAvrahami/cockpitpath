CockpitPath — Public Site & Application Shell
Same shell as Guide Mode and Aircraft Page: near-black surfaces, cyan reserved for the one action that matters, mono for aircraft/technical values, serif only for longer explanation. The homepage is dark rather than a light SaaS page, because the product it is selling is dark. Sign-in routes straight into the existing Aircraft Page — no separate dashboard or empty aircraft library is introduced.
