CockpitPath Guide Mode — three directions
Same product, same step: Power Up, Step 4 of 16, Turn Battery ON. Each direction is shown as wide desktop, narrow companion window (480 px) and iPad landscape. The QUICK | LEARN switch is live in every frame — 1a and 1b open in Learn, 1c opens in Quick.
1a
Direction A — Precision Aviation
Operational and restrained. Near-black cool greys, a single amber signal colour reserved for the action and the highlighted control, technical values set in mono. Dense labelling and a segmented step ruler give the interface an instrument-grade feel without imitating avionics.
