PUBLIC SITE & SHELL · v2 · REFINEMENT OF v1
CockpitPath — Public Site & Application Shell, Refined
v1 solved structure but stayed flat — black, text, black, cards, black. This pass keeps every locked decision (Guide Mode / Cockpit Explorer / Aircraft Systems positioning, the one-aircraft-first model, auth simplicity, Route & Fix) and rebuilds the homepage as visual storytelling: four dark surface levels instead of one, a cockpit-dominant hero, and each learning mode getting its own full visual treatment instead of a feature card. It also adds the piece v1 didn't have: a real App Home for signed-in users, and a public header that stays public even when you're signed in.
