# Phase 8 — Content Expansion

**Status:** ⬜ Planned

## Goal

Expand the verified Boeing 737 MAX 8 / iFly / Microsoft Flight Simulator 2024 `Cold & Dark → Takeoff` journey across its canonical structure.

## Why Now

Broad content production should begin only after the complete author–validate–publish–learn–resume–explore–understand loop works for the first vertical slice.

## Deliverables

The canonical journey sections are:

1. Power Up
2. IRS & Navigation
3. Overhead Preparation
4. FMC Initialization
5. Route Setup
6. Performance Setup
7. MCP Preparation
8. Before Pushback
9. Pushback
10. Engine Start
11. After Start
12. Taxi
13. Before Takeoff
14. Takeoff

Content expansion includes:

- Verified procedure content.
- Approved real cockpit imagery for the supported simulator and aircraft implementation.
- Controls.
- Hotspots.
- Concepts.
- Aircraft Systems and System Components.
- Source references.
- Complete verification metadata.

Exact step counts remain intentionally unspecified and must emerge from verified content production.

## Exit Criteria

- All 14 sections needed for the v0.1 journey are represented by coherent, validated, published content.
- Applicable procedures and technical claims meet verification policy.
- Real cockpit imagery and hotspot use are approved and traceable.
- Controls, concepts, systems, and cross-links resolve.
- Source references and verification metadata are complete.
- No exact step target is treated as a substitute for quality, accuracy, and coverage.

## Dependencies

Phases 2–7 and an operating content verification workflow.
