# CockpitPath Authored Content

This directory is the repository-owned source for structured CockpitPath content.
Files are UTF-8 YAML, may contain multiple YAML documents, and use stable content
keys rather than database UUIDs. Markdown is permitted only in schema-approved
rich-text fields.

The current catalog contains draft product identity metadata only. It deliberately
contains no aircraft procedures, control locations, simulator behavior, or other
technical claims. Technical content cannot become `PUBLISHED` until its sources
and a matching verification event satisfy the publishing validator.

See the [authoring guide](../docs/content/authoring-guide.md), [key conventions](../docs/content/content-key-conventions.md), and [publishing workflow](../docs/content/publishing-workflow.md).
